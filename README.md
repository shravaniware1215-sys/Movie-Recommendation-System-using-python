# 🎬 Movie Recommendation System

A simple **Streamlit app** that recommends movies based on their genre.  
The dataset is stored in an Excel file (`Movie_Name.xlsx`) containing movie names, genres, and release years.

---

## 🚀 Features
- Display the full movie dataset
- Select a genre from the dropdown
- Get recommended movies instantly
- Interactive UI powered by Streamlit

---

## 📂 Dataset
The Excel file should have the following columns:
- **Movie Name** → Title of the movie  
- **Genre** → Category/genre of the movie  
- **Year** → Release year  

Example:

| Movie Name      | Genre            | Year |
|-----------------|------------------|------|
| Inception       | Science Fiction  | 2010 |
| Titanic         | Romance/Drama    | 1997 |
| Parasite        | Thriller/Drama   | 2019 |
